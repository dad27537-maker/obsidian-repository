# Gongkao AI Skill Hub - Obsidian 知识库版

这是一个面向国考、省考、事业单位考试的 Obsidian AI 备考知识库。

它将「考公知识库 + AI Skill + 错题复盘 + 申论批改 + 面试模拟 + 复习计划」整合为一个可持续迭代的学习系统。

## 推荐使用方式

1. 用 Obsidian 打开本文件夹作为 Vault。
2. 从 `00-首页.md` 开始。
3. 每次学习时，先打开对应 Skill。
4. 做题后使用 `错题模板.md` 记录。
5. 每周使用 `周复盘模板.md` 复盘。
6. 申论、面试、岗位选择可直接复制 `prompts/` 里的提示词到 AI 对话中使用。

## 核心模块

- `skills/`：AI Skill 说明文件
- `prompts/`：可直接复制给 AI 的提示词
- `templates/`：Obsidian 日常记录模板
- `知识库/`：行测、申论、面试、时政、岗位选择知识框架
- `错题本/`：错题沉淀区
- `复习计划/`：每日、每周、阶段计划
- `素材库/`：申论和面试素材沉淀

## 项目定位

不是资料合集，而是一个 AI 辅助的考公备考工作流。
