# Skill 使用说明

本知识库中的 Skill 是给 AI 使用的角色与流程说明。

## 使用方法

打开任意 `SKILL.md`，复制其中内容给 AI，然后再输入你的题目、答案、材料或备考情况。

## 推荐工作流

### 行测
题目 → AI 解析 → 记录错题 → 标注知识点 → 安排二刷

### 申论
材料 + 我的答案 → AI 批改 → 提炼要点 → 改写答案 → 沉淀模板

### 面试
AI 出题 → 我作答 → AI 评分 → 优化表达 → 记录亮点句

### 复习计划
目标考试 + 剩余天数 + 每日时间 → AI 生成计划 → 每日打卡 → 周复盘
