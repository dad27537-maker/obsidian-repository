# 资料分析总览

## 常见考点

- 增长率
- 增长量
- 比重
- 平均数
- 倍数
- 基期与现期
- 混合增长率

## 核心能力

- 快速定位数据
- 判断公式
- 估算
- 单位换算
- 比较大小

## 高频公式

- 增长率 = 增长量 / 基期量
- 基期量 = 现期量 / (1 + 增长率)
- 增长量 = 现期量 × 增长率 / (1 + 增长率)
- 比重 = 部分 / 整体
